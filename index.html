Core Capabilities

Built with speed, security, and developer ergonomics in mind. Inspect local architecture honestly without bloated cloud middleware.

100% Local & Private

All traffic capture is intercepted locally on your loopback device. None of your authentication tokens, payload payloads, or API response bodies ever hit our servers.

Zero-Configuration Proxy

Simply route your server requests through Portlight's proxy daemon. No manual root certificate setups, or DNS overrides required. It just intercept port sockets.

Instant Shareable Tunnels

Generate secure public tunnels with one command. Excellent for validating Webhook payloads (Stripe, GitHub), testing mobile applications, or demoing to collaborators.

Detailed Request Timings

Pinpoint slow database calls or heavy assets. View breakdown timelines showing connection handshakes, request uploads, server processing, and response delivery.

Command Line Interface

Control Portlight directly from your terminal. Lightweight, memory-efficient daemon written in Go.

zsh — portlight-cli
$ portlight start 3000
